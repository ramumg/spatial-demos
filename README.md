# Location Intelligence with Oracle APEX

Demo app from the LAOUC 2026 session *Location Intelligence with Oracle APEX: Geocoding, Spatial Studio and Native Maps*.

One Oracle APEX app, **Location Intelligence LATAM**, answers four spatial questions about 15 sites in Mexico, Guatemala, Brazil, Uruguay, Argentina and Paraguay:

| Question | App page | Spatial feature |
| --- | --- | --- |
| Where is this address? | Geocoding | `SDO_GCDR.ELOC_GEOCODE_AS_GEOM` |
| What's near me? | Near Me | `SDO_NN`, `SDO_WITHIN_DISTANCE`, `SDO_DISTANCE` |
| What's inside a zone? Where are the gaps? | Regional Coverage, Coverage Gaps | `SDO_ANYINTERACT`, `SDO_DISTANCE` |
| What's the best route to serve or deliver? | Distribution Routes | Spatial Studio driving routes, embedded in APEX |
| Ask any of these in plain language | Ask the Map | Select AI (`DBMS_CLOUD_AI.GENERATE`) + APEX Map |

Everything stays in the database: Spatial Studio writes route geometry, drive time and distance back to `LAOUC_LOCATIONS`, and APEX reads that table directly.

## Requirements

- Oracle Autonomous Database (26ai) with Oracle Spatial
- Oracle APEX 26.1 or later (the export was made on 26.1)
- Oracle Spatial Studio, for the Distribution Routes page
- A Select AI profile, for the Ask the Map page

## Setup

1. **Database.** In your APEX workspace schema, run in order:
   - `database/01_tables.sql`
   - `database/02_sample_data.sql`
   - `database/03_views.sql`
2. **APEX app.** Import `apex/f103.sql` (see [apex/README.md](apex/README.md)).
3. **Spatial Studio project.** Create a project with `LAOUC_LOCATIONS` as a dataset, then:
   - Run **Calculate driving route** from each location to *Centro de Distribución CDMX*, storing drive time (minutes), distance (km) and the route geometry in `DRIVE_TIME`, `DRIVE_DISTANCE` and `ROUTE_GEOM`.
   - Add a **nearest neighbors** analysis: the 3 nearest sites to each hub.
   - Add layers for the hubs, the network by `CATEGORY`, the routes and the service areas.
   - Publish the project and connect it to Page 6 (see [apex/README.md](apex/README.md)).
4. **Select AI.** Create a profile named `GENAI_PROFILE` with `DBMS_CLOUD_AI.CREATE_PROFILE`, using your own AI provider credential and an object list that includes `LAOUC_LOCATIONS` and `LAOUC_REGIONS`.

## Security notes

- Replace the Spatial Studio token in the app export with a placeholder before committing it. Add your token and AI credentials in your own environment only.
- Ask the Map runs only single-statement `SELECT`/`WITH` queries generated by Select AI.
